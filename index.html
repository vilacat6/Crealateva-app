Com treballarem?

1. Baixa un ZIP. 2. Extreu-lo. 3. Obre la carpeta a Visual Studio Code. 4. Obre index.html a Chrome. 5. Desa amb Ctrl+S i recarrega amb F5. Quan acabis, ensenya el resultat al professor.
