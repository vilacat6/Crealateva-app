Què necessites?

Per programar i provar

Un ordinador amb Visual Studio Code i un navegador com Chrome. No cal GitHub, Vercel ni Live Server.

Per crear el projecte amb IA

Una eina d’IA que el centre autoritzi, amb supervisió quan correspongui. Si no tens accés, hi ha plantilles per continuar.
