Obre la teva primera web a l’ordinador

Una web no apareix per màgia: són fitxers guardats en una carpeta. Avui aprendràs a obrir-los.

La teva missió: Descarregar una web, trobar els seus fitxers i fer-la funcionar a Chrome.

Traducció de paraules difícils

ZIPUna carpeta comprimida. Primer cal extreure-la.
Visual Studio CodePrograma per obrir i canviar els fitxers de la web.
index.htmlEl fitxer principal que obre la web al navegador.

Segueix aquests passos (d’un en un)

1

Baixa el projecte

Prem el botó «Baixar la primera web (ZIP)» que tens a sota. Windows el guardarà normalment a «Descàrregues».

✔ Comprova: És un fitxer que acaba en .zip.
2

Extreu el ZIP

Obre l’Explorador de fitxers de Windows (icona de carpeta groga, a la barra de baix). Entra a «Descàrregues». Fes clic dret al ZIP → «Extreu-ho tot» → «Extreu». Entra a la nova carpeta extreta.

✔ Comprova: Dins has de veure index.html, style.css i script.js. No treballis dins del ZIP.
3

Obre la carpeta a VS Code

Obre Visual Studio Code. A dalt, prem File → Open Folder (Fitxer → Obre carpeta). Selecciona la carpeta que acabes d’extreure, la que té index.html. Prem «Selecciona carpeta». Si et pregunta si confies en els fitxers, accepta només perquè són la plantilla del professor.

✔ Comprova: A l’esquerra de VS Code has de veure els tres fitxers.
4

Obre la web a Chrome

Torna a l’Explorador de Windows (la carpeta extreta, no VS Code). Fes doble clic a index.html. Si no s’obre amb Chrome, fes clic dret → «Obre amb» → Google Chrome.

✔ Comprova: Hauries de veure una pàgina que diu «La meva primera web».
5

Prova un botó

A la pàgina, escriu un nom inventat o el teu nom de pila al camp i prem «Saluda’m!».

✔ Comprova: Apareix un missatge que comença amb «Hola, ...».
6

Distingeix els dos programes

Deixa oberts VS Code i Chrome: a VS Code canviaràs el codi; a Chrome veuràs si funciona. No cal Live Server ni publicar res.

✔ Comprova: Saps tornar d’una finestra a l’altra amb Alt+Tab.

La plantilla d’aquesta missió: ⬇ Baixar 01-primera-web.zip

Important: a Windows, extreu el ZIP abans d’editar els fitxers.

✅ Com sé que he acabat?

No cal que ho lliuris tot aquí. Ensenya el resultat si t’ho demana el professor.

⚡ Si acabes abans (opcional)

Sense modificar res, fes clic a index.html, style.css i script.js dins de VS Code. Mira com cada fitxer conté un text diferent.

🆘 Què faig si em quedo encallat?

Si no tens VS Code instal·lat, fes servir l’ordinador preparat pel centre; per aquesta pràctica no cal instal·lar res més.

Obre Ajuda. També pots dir al professor: «Sóc al pas [NÚMERO] i em passa [QUÈ VEIG]».
