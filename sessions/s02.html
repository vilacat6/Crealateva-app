Fes funcionar la primera web

Veure una web que respon quan prems un botó.

🖥️

👉 Fes això, per ordre

  1. Descarrega la pràctica

    Prem «Baixar primera web» i extreu els arxius del ZIP.

  2. Obre-la a Visual Studio Code

    File → Open Folder → escull la carpeta que conté index.html.

  3. Prova-la

    Fes doble clic a index.html des de l’Explorador de Windows. Escriu un nom i prem «Saluda’m!».

  4. Canvia tres coses

    A index.html: canvia «La meva primera web». A style.css: canvia #3156d3 per #187665. A script.js: canvia «Hola» per «Benvingut/da». Desa amb Ctrl+S.

  5. Comprova

    Recarrega la web (F5) i assegura’t que el títol, el color i el missatge han canviat.

Això és el que aconseguiràs

1 · Escrius un nom

Ex.: Aina

2 · Prems el botó

Saluda'm!

3 · Apareix el missatge

Hola, Aina!
