🖥️ Fes funcionar la primera web

Obrir el projecte de mostra i modificar HTML, CSS i JavaScript.

👉 Fes aquests passos

  1. Descarrega la plantilla

    A la secció «Pràctica per descarregar», prem «Baixar la primera web (ZIP)». Obre la carpeta «Descàrregues» de Windows, fes clic dret al ZIP i tria «Extreu-ho tot». Entra a la carpeta extreta: hi trobaràs index.html, style.css i script.js.

  2. Obre la carpeta amb Visual Studio Code

    Obre Visual Studio Code. Al menú superior, prem File → Open Folder (Fitxer → Obre carpeta), selecciona la carpeta que conté index.html i prem «Selecciona carpeta». A l’esquerra apareixeran els tres fitxers.

  3. Comprova la versió inicial

    Sense tancar VS Code, obre la mateixa carpeta a l’Explorador de Windows i fes doble clic a index.html. Al navegador, escriu el teu nom, prem «Saluda’m!» i comprova que apareix «Hola, ...».

  4. Canvia el títol visible de la pàgina

    A VS Code, fes clic a index.html. Prem Ctrl+F, escriu «<h1>La meva primera web</h1>» i prem Esc. Canvia només el text del mig per «La web de l’Àlex» (o el teu nom). No esborris <h1> ni </h1>.

  5. Canvia el color del botó

    A VS Code, fes clic a style.css. Prem Ctrl+F i busca «background:#3156d3». Canvia només «#3156d3» per «#187665». No esborris «background:» ni el punt i coma.

  6. Canvia el missatge

    Obre script.js, prem Ctrl+F i busca «Hola, ». A la línia de resultat.textContent canvia «Hola, » per «Benvingut/da, ». Mantén les cometes, els signes + i la resta de la línia.

  7. Desa i comprova els tres canvis

    A VS Code prem Ctrl+S a cada fitxer que has modificat. Torna al navegador i prem F5. Comprova el títol nou, el botó verd i el missatge «Benvingut/da, ...». Si no canvia, revisa que tens oberta la carpeta extreta, no el ZIP.

ABANS · Cerca aquest text
<h1>La meva primera web</h1>
DESPRÉS · Així ha de quedar
<h1>La web de l’Àlex</h1>

style.css · color del botó

ABANS · Cerca aquest text
button{background:#3156d3;color:white;
DESPRÉS · Així ha de quedar
button{background:#187665;color:white;

script.js · salutació

ABANS · Cerca aquest text
resultat.textContent = 'Hola, ' + nom + '! Has fet una web interactiva.';
DESPRÉS · Així ha de quedar
resultat.textContent = 'Benvingut/da, ' + nom + '! Has fet una web interactiva.';
Important

El text de <title> canvia la pestanya del navegador; el de <h1> canvia el títol gran visible. Aquí modifiquem <h1>.
