🖥️ Fes funcionar la primera web

Obrir index.html i canviar tres coses.

👉 Fes aquests passos

  1. Descarrega els fitxers

    Baixa la primera web (ZIP), fes clic dret al ZIP i tria «Extreu-ho tot».

  2. Obre la carpeta

    A Visual Studio Code: File → Open Folder. Escull la carpeta extreta, la que conté index.html.

  3. Prova-la al navegador

    Des de l’Explorador de Windows, fes doble clic a index.html. Escriu el nom i prem «Saluda’m!».

  4. Canvia el codi

    Canvia el títol a index.html, el color #3156d3 per #187665 a style.css i «Hola» per «Benvingut/da» a script.js.

  5. Desa i mira el resultat

    Prem Ctrl+S a Visual Studio Code i després F5 al navegador. Comprova els tres canvis.
