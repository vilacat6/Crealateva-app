👉 Fes aquests passos

  1. Prepara els dos arxius que faràs servir

    A l’Explorador de Windows localitza la carpeta final del projecte i el fitxer «NomCognom_projecte_FINAL.zip». Si no tens el ZIP, torna a la sessió 9.

  2. Obre la teva web

    Entra a la carpeta del projecte i fes doble clic a index.html. Comprova que estàs veient la teva versió modificada.

  3. Explica què has creat

    Prepara una frase: «He creat una aplicació de ... que serveix per ...». Digues quina plantilla vas triar i per què.

  4. Fes una demostració de dos minuts

    Mostra el títol propi i fes funcionar almenys un botó. Si el joc té reinici, demostra també que funciona.

  5. Explica un canvi concret

    A VS Code obre el fitxer on has fet el canvi (index.html, style.css o script.js) i assenyala el text que has modificat. Explica si afecta el contingut, els colors o una acció.

  6. Entrega el ZIP final

    Puja el fitxer «_FINAL.zip» a l’aula virtual o lliura’l a la carpeta indicada pel professor. No lliuris només index.html perquè faltaria l’estil o el comportament.
