Guarda una versió amb Git

Aprendre a guardar una versió sense perdre el treball.

📦

👉 Fes això, per ordre

  1. Obre el projecte a Visual Studio Code

    Comprova que estàs a la carpeta correcta.

  2. Obre «Source Control»

    Prem la icona de branques de l’esquerra o Ctrl+Shift+G.

  3. Inicialitza Git si cal

    Si veus «Initialize Repository», prem-lo. Si no, continua.

  4. Guarda la versió

    Prem + per afegir els canvis. Escriu «La meva primera versió» i prem Commit.

  5. Mostra-ho

    Ensenya al professor el commit creat. Ja tens una versió guardada en aquest ordinador.

✅ Quan hagis acabat...

Mostra un commit al professor. No és necessari publicar a GitHub.

🎯 Avui només cal...

Fes una còpia de control del teu projecte.

💡 Una ajuda

Git no és el mateix que GitHub: ara només has de guardar la versió local.

🚀 Si acabes abans

Només amb autorització: publica el repositori a GitHub amb ajuda del professor.
