Guardar versions amb Git i GitHub

Objectiu: Entendre la diferència entre fitxer local, commit i repositori remot.

Què farem avui?

10 min Què és un commit?
10 min Comprovar Git
15 min Inicialitzar i fer dos commits
15 min Publicar opcionalment a GitHub
5 min Comprovar historial

Instruccions pas a pas

  1. Comprova. Obre Terminal > New Terminal i executa git --version.
  2. Inicialitza. A Source Control, prem Initialize Repository.
  3. Registra. Fes un commit inicial i un segon commit després d’un petit canvi.
  4. Publica. Només amb autorització: Publish to GitHub, repositori privat i comprovar fitxers al web.

Comprova que ho has aconseguit

Repte opcional

Explica diferència entre commit i push. Recupera el contingut d’un fitxer des del seu historial sense perdre treball.

Si pots utilitzar IA amb autorització

Aquest prompt és orientatiu. També pots treballar amb una resposta preparada pel docent, sense compte personal.

Explica la diferència entre Git, GitHub, commit i push amb l’analogia d’un videojoc que guardo en versions.

Què has de lliurar?

Captura d’historial de dos commits, o registre local del docent si no hi ha compte.
