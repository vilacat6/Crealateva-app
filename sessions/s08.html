Veiem com es publica

Comprovar una app publicada amb ajuda del professor.

🌍

👉 Fes això, per ordre

  1. Mira la demostració del professor

    El professor mostrarà com el codi de GitHub arriba a Vercel.

  2. Obre l’enllaç de classe

    El professor t’enviarà l’adreça del projecte publicat.

  3. Prova la web publicada

    Prem dos botons i comprova que fan el mateix que en el teu ordinador.

  4. Digueu què heu vist

    Explica en una frase què és Vercel: un servei per publicar webs.

  5. Comprova el teu projecte

    Verifica que el teu index.html funciona. El professor decidirà quins projectes es publiquen.

✅ Quan hagis acabat...

Mostra que saps obrir i provar una web publicada.

🎯 Avui només cal...

Descobreix com arriba una web a internet.

💡 Una ajuda

No has de crear cap compte de Vercel. La publicació la pot fer el professor.

🚀 Si acabes abans

Si el professor et dona permís, prova la publicació del teu projecte.
