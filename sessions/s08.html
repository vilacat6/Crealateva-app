🔍 Revisa el treball en local

Aprendre a revisar una web sense publicar-la.

👉 Fes aquests passos

  1. Obre el ZIP que has guardat

    Fes clic dret → «Extreu-ho tot»; no intentis editar fitxers dins del ZIP.

  2. Obre la còpia extreta

    A Visual Studio Code obre la carpeta extreta amb File → Open Folder.

  3. Executa index.html

    Des de Windows fes doble clic a index.html. No necessites cap compte ni servidor.

  4. Revisa dos elements

    Comprova que el títol és correcte i que una acció funciona.

  5. Ensenya el resultat

    Mostra al professor o a un company la còpia en funcionament.

✅ Quan acabis

La web funciona també obrint-la des de la còpia extreta del ZIP.
