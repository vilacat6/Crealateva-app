  2. Baixa el projecte

    A la pàgina «Exemples» descarrega només el ZIP del teu projecte i extreu-lo.

  3. Obre’l i prova’l

    Obre la carpeta amb Visual Studio Code. Obre index.html amb doble clic i prova els botons.

  4. Canvia el nom i un color

    Modifica el títol dins de h1 a index.html i un color de style.css.

  5. Desa i comprova

    Ctrl+S a Visual Studio Code; F5 al navegador.
