🎨 Personalitza la teva aplicació

Canviar els textos i el color d’una de les plantilles sense trencar-ne els botons.

👉 Fes aquests passos

  1. Tria el projecte real

    Obre la plantilla que has triat a la sessió 1 (quiz, tasques o futbol). Descarrega’n el ZIP a «Exemples» i extreu-lo. Obre la carpeta extreta a VS Code amb File → Open Folder.

  2. Localitza el títol

    Fes clic a index.html. Prem Ctrl+F i escriu «<h1>». Trobaràs el títol principal. Canvia només les paraules entre <h1> i </h1> pel nom que vas triar. El text inicial depèn de la plantilla.

  3. Localitza el color del botó

    Obre style.css, prem Ctrl+F i busca «background:#3156d3». Si fas el marcador, aquesta cadena controla el botó de l’equip blau; si fas quiz o tasques, controla els botons principals.

  4. Canvia el color

    Substitueix el valor «#3156d3» per «#187665». Mantén la resta del codi intacte i desa amb Ctrl+S.

  5. Obre el projecte i comprova’l

    Des de Windows obre index.html de la mateixa carpeta. Prem F5. Comprova el títol nou i prova una acció (respondre, afegir una tasca o marcar un gol).

index.html · marcador de futbol (exemple)

ABANS · Cerca aquest text
<h1>El meu marcador</h1>
DESPRÉS · Així ha de quedar
<h1>SuperGol</h1>

style.css · color

ABANS · Cerca aquest text
background:#3156d3
DESPRÉS · Així ha de quedar
background:#187665
Important

Els fragments d’exemple són del marcador; en el quiz o les tasques, el text del <h1> és diferent. Utilitza Ctrl+F per buscar el fragment que tens realment.
