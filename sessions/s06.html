🔎 Comprova que funciona

Utilitzar una llista de proves per identificar i corregir errors senzills.

👉 Fes aquests passos

  1. Fes una còpia de seguretat

    A l’Explorador de Windows, fes clic dret sobre la carpeta del projecte → Copia. Enganxa-la al mateix lloc i posa-li de nom «projecte_copia». Treballa a la carpeta original.

  2. Prova la pàgina

    Obre index.html des de l’Explorador de Windows. Comprova que es mostra el títol i que els botons responen. Apunta «Funciona» o «No funciona» a la fitxa de proves.

  3. Revisa l’HTML si falta un text

    A VS Code obre index.html. Prem Ctrl+F i busca «<h1>». Si falta el títol principal, escriu les paraules entre <h1> i </h1>. No eliminis aquestes etiquetes.

  4. Revisa el CSS si no es veu el nou color

    Obre style.css i busca amb Ctrl+F el color «#187665» que vas escriure. Si encara hi surt «#3156d3» al botó, repeteix el canvi i prem Ctrl+S.

  5. Revisa el JavaScript si un botó no respon

    Obre script.js i busca «addEventListener». Comprova que el nom entre cometes del getElementById coincideix amb l’id del botó a index.html. No canviïs res si no tens clar què falla: mostra-ho al professor.

  6. Registra i comprova

    Escriu un problema detectat i què has fet per resoldre’l. Desa els canvis amb Ctrl+S i prem F5 al navegador per repetir la prova.

index.html + script.js · noms que han de coincidir

ABANS · Cerca aquest text

DESPRÉS · Així ha de quedar
document.getElementById('saludar')
