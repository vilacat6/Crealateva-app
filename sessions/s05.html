⚙️ Canvia com funciona

Fer que l’aplicació respongui amb un missatge diferent quan hi interactues.

👉 Fes aquests passos

  1. Obre el projecte que estàs personalitzant

    A VS Code obre la mateixa carpeta de la sessió 4, la que conté script.js. Fes clic a script.js a la columna esquerra.

  2. Troba el missatge actual

    Prem Ctrl+F. Segons el teu projecte, busca: futbol «Gol! L’equip blau ha marcat.»; quiz «Molt bé! Resposta correcta.»; tasques «Escriu una tasca abans d’afegir-la.».

  3. Substitueix només el text entre cometes

    Escriu un missatge nou sense canviar cometes, punts i coma, ni noms de variables. Per exemple, al futbol canvia «Gol! L’equip blau ha marcat.» per «Goooool de l’equip blau!».

  4. Guarda el fitxer correcte

    Prem Ctrl+S mentre tens script.js obert. Si el nom del fitxer mostrava un punt blanc, ha de desaparèixer quan el deses.

  5. Prova la funcionalitat

    Al navegador prem F5 i executa l’acció corresponent: gol blau, resposta correcta o clic al botó Afegir amb el camp buit. Comprova que apareix el nou text.

  6. Comprova que no s’ha trencat res

    Repeteix l’acció o prova un altre botó. Si falla, compara el codi amb l’exemple abans/després i assegura’t que no has esborrat cap cometa.

script.js · marcador de futbol (exemple)

ABANS · Cerca aquest text
missatge.textContent = 'Gol! L’equip blau ha marcat.';
DESPRÉS · Així ha de quedar
missatge.textContent = 'Goooool de l’equip blau!';

✅ Quan acabis

Una acció de l’app mostra el teu missatge nou i les altres accions continuen funcionant.

🎯 Missió d’avui

Fer que l’aplicació respongui amb un missatge diferent quan hi interactues.

🚀 Si acabes abans (opcional)

Al futbol, canvia també el missatge de l’equip vermell. Al quiz, canvia el text de resposta incorrecta. A tasques, canvia el text del botó «Eliminar» buscant «eliminar.textContent».

🔁 Comprovar canvis

Desa amb Ctrl+S a Visual Studio Code. Després prem F5 al navegador.
