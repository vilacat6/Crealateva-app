Materials d'ajuda

Guies ràpides

1. Preparar Visual Studio Code

  1. Desa el ZIP del projecte i extreu-ne tots els fitxers.
  2. Obre Visual Studio Code i selecciona File > Open Folder.
  3. Tria la carpeta extreta que conté index.html.
  4. Troba els fitxers amb Explorer. Obre index.html amb el navegador.
  5. Modifica, desa amb Ctrl+S i recarrega la pàgina.

2. Els tres llenguatges

HTML

Què hi ha? Títols, camps, botons, imatges.

<button id="jugar">Juga</button>

CSS

Com es veu? Colors, espais i distribució.

button { background: blue; }

JavaScript

Què fa? Detectar clics i canviar textos.

button.addEventListener('click', jugar);

3. Git i GitHub

  1. Instal·la Git si el professor ho indica, i comprova git --version.
  2. Obre Source Control > Initialize Repository.
  3. Stage dels fitxers, escriu un missatge i prem Commit.
  4. Només si tens compte autoritzat, publica amb Publish to GitHub. Comença amb repositori privat.
  5. Els nous commits són locals fins que fas Push o Sync Changes.

4. Vercel (habitualment a càrrec del docent)

  1. Comprova que index.html és a l'arrel del projecte.
  2. Entra a Vercel amb un compte autoritzat i importa el repositori de GitHub.
  3. Per una web estàtica: Framework Preset Other, sense ordre de compilació.
  4. Prem Deploy. Obre l'URL i verifica els botons.
  5. Quan s'actualitzi GitHub, el projecte connectat es pot tornar a desplegar automàticament.

5. Bones pràctiques amb la IA

Descriu el context, l'objectiu, el fitxer que vols canviar i com comprovaràs el resultat. Demana canvis petits. Llegeix, prova i explica la solució abans de continuar. Si no tens autorització, treballa amb els exemples que doni el professorat.
