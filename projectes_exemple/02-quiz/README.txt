JOC DE PREGUNTES
1. Obre index.html al navegador i contesta una pregunta.
2. Canvia el títol a index.html.
3. Canvia el color d’un botó a style.css.
4. A script.js canvia UNA pregunta i comprova la resposta correcta (número 0, 1 o 2).
5. Desa amb Ctrl+S i recarrega amb F5.

Per comprovar els canvis: Ctrl+S a Visual Studio Code i F5 al navegador. Sense servidor, GitHub ni Vercel.
