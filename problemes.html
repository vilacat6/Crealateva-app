Ajuda real per a principiants

Què faig si no em surt?

Busca el problema que s’assembla al teu i obre’l. Molts errors tenen una solució de dos clics.

He baixat el ZIP però no sé què fer

Obre l’Explorador de Windows → Descàrregues. Clic dret al ZIP → Extreu-ho tot → Extreu. Entra a la carpeta nova. No editis directament des del ZIP.

A VS Code no veig els fitxers

A dalt: File → Open Folder. Tria la carpeta que conté index.html. Mira la columna esquerra. Si encara no hi és, comprova que has extret el ZIP.

He canviat el codi, però Chrome mostra el mateix

A VS Code prem Ctrl+S. Torna a Chrome i prem F5. Revisa que Chrome ha obert index.html de LA MATEIXA carpeta que tens oberta a VS Code.

Veig text de codi en lloc de la web

Potser has desat index.html.txt o has copiat les marques ```html. El fitxer ha de dir-se exactament index.html i començar per <!doctype html>. Demana al professor que comprovi les extensions.

La IA m’ha donat tres fitxers o parla de React, npm o servidor

Respon: «Torna a fer la mateixa idea en un sol index.html amb HTML, CSS i JavaScript dins del fitxer. Ha de funcionar fent doble clic, sense instal·lar res». Si continua fallant, baixa un exemple d’un fitxer.

El botó no fa res quan clico

Comprova que tens oberta la versió correcta. Desa i prem F5. Si segueix igual, apunta què esperes i què passa; utilitza el prompt de reparació de la missió 6.

He esborrat alguna cosa sense voler

A VS Code prem Ctrl+Z per desfer. Si ja has desat massa canvis, recupera la teva còpia «projecte-abans-millora» o torna a extreure la plantilla.

El CSS ha desaparegut o els colors es veuen estranys

Si treballes amb tres fitxers, index.html, style.css i script.js han de quedar junts a la mateixa carpeta. Si treballes amb un sol index.html creat amb IA, comprova que la IA hagi inclòs el CSS dins de <style>.

La web fa servir Internet i a casa no funciona

Demana a la IA una versió que no depengui d’imatges, llibreries ni serveis externs. La pàgina del projecte s’ha de poder obrir des de l’Explorador de Windows, sense servidor.

No em funciona l’eina d’IA o no hi tinc accés

No inventis comptes ni utilitzis eines sense autorització. Pots continuar amb els exemples d’un sol fitxer i explicar al professor quina millora vols fer.

La IA em retorna massa codi

No cal entendre cada línia. Explica-li: «Simplifica-ho a una pantalla i dos botons com a màxim. Dona’m només el fitxer complet index.html». Si falla, demana suport al professor.

No sé com lliurar el projecte

Comprimeix la carpeta sencera a ZIP i entrega-la per la plataforma indicada pel professor. No cal GitHub ni Vercel.

Una frase útil per demanar ajuda: «Soc a la missió 5, pas 5. Espero veure la web, però Chrome em mostra codi. El meu fitxer es diu index.html.txt». Com més concret siguis, més fàcil és ajudar-te.
Per als teus projectes: VS Code → Ctrl+S → Chrome → F5. No cal publicar res.
