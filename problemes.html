Ajuda ràpida

No funciona? Prova això.

Fes una comprovació cada vegada. Si encara no funciona, ensenya-ho al professor.

❓ No veig els colors

Comprova que style.css està al mateix directori que index.html i prem Ctrl+S i F5.

❓ El botó no fa res

Comprova que existeix script.js, que els noms són correctes i ensenya la consola F12 al professor.

❓ No sé on són els fitxers

Torna al ZIP, extreu-ho tot i obre la carpeta correcta amb File → Open Folder.

❓ El navegador no mostra els canvis

Desa a Visual Studio Code amb Ctrl+S i després recarrega amb F5.

❓ El ZIP no s’obre

Clic dret al ZIP a Windows → Extreu-ho tot. Obre la carpeta descomprimida, no el fitxer ZIP.

❓ A GitHub falten carpetes

Per pujar el projecte complet des de VS Code, copia les carpetes dins del repositori clonat; fes commit i push. El professor t’ajudarà.

❓ No tinc GitHub o Vercel

No passa res: pots completar les activitats en local. El professorat s’encarrega de publicar-les.
