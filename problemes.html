Consulta abans de demanar ajuda

Què faig si no funciona?

Reprodueix el problema, obre F12 > Console, comprova el nom del fitxer i fes un canvi cada vegada.

Pàgina en blanc

Què provar: Revisa que el fitxer es digui index.html; obre F12 > Console; comprova errors de sintaxi.

Possible causa: index.html no és present; un script trenca la càrrega.

CSS no s’aplica

Què provar: Comprova <link rel="stylesheet" href="style.css">, la carpeta i el nom exacte; desa i recarrega.

Possible causa: Ruta incorrecta o nom amb majúscules.

Botó no respon

Què provar: Busca errors a la consola, verifica els id i que JS es carregui amb defer.

Possible causa: L’ID no coincideix o el fitxer no carrega.

Canvis no apareixen

Què provar: Ctrl+S, recarrega amb Ctrl+F5 i comprova que edites el projecte correcte.

Possible causa: Canvis sense desar o pestanya antiga.

git no es reconeix

Què provar: Instal·la Git; reinicia VS Code i repeteix git --version.

Possible causa: Git no és al PATH.

No puc fer commit

Què provar: Fes Stage amb +; escriu missatge; configura autor amb compte autoritzat si Git ho demana.

Possible causa: Fitxers no afegits o autor desconegut.

El commit no surt a GitHub

Què provar: Commit és local; revisa si has fet Push o Sync i si el repositori remot és correcte.

Possible causa: Falta push.

Error 404 a Vercel

Què provar: Comprova index.html a l’arrel publicada; preset Other, build buit, directori correcte.

Possible causa: Root directory o output equivocats.

Funciona localment però no publicat

Què provar: Revisa rutes relatives i majúscules/minúscules; comprova assets a GitHub.

Possible causa: Rutes locals absolutes, fitxers no pujats.

La IA em canvia tot el projecte

Què provar: Demana el canvi mínim i només un fitxer; guarda un commit abans de provar.

Possible causa: Prompt massa genèric.

La pantalla és massa ampla al mòbil

Què provar: Inclou meta viewport i CSS amb max-width, flex/grid adaptables.

Possible causa: Amplades fixes.

Perdo dades en recarregar

Què provar: Explica la diferència entre variables temporals i localStorage.

Possible causa: No hi ha persistència.
