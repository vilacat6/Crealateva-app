Com començo?

Només necessites Visual Studio Code i un navegador

  1. Baixa el ZIP del teu projecte des de la sessió.
  2. Extreu el ZIP amb clic dret → Extreu-ho tot.
  3. Obre la carpeta a Visual Studio Code: File → Open Folder.
  4. Fes doble clic a index.html des de l’Explorador de Windows: s’obre al navegador.
  5. Modifica el codi, desa amb Ctrl+S i després actualitza el navegador amb F5.
  6. Lliura el ZIP final quan t’ho indiqui el professor.
