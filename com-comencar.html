Guia ràpida

Com començo?

📁 1. Baixa el ZIP

Fes clic al botó de descàrrega de la sessió o a «Projectes».

📂 2. Extreu-lo

A Windows: clic dret al ZIP → Extreu-ho tot.

🖥️ 3. Obre la carpeta

A Visual Studio Code: File → Open Folder.

Com provo la meva web?

  1. Troba el fitxer index.html

    El trobaràs a la carpeta descomprimida del projecte.

  2. Obre’l amb el navegador

    Fes doble clic al fitxer des de l’Explorador de Windows.

  3. Desa els canvis amb Ctrl+S

    Quan canviïs algun fitxer a Visual Studio Code, desa’l.

  4. Actualitza el navegador amb F5

    Comprova que apareixen els canvis.

Per a què serveix cada fitxer?

🧱 index.html

Posa els botons, els textos i les pantalles.

🎨 style.css

Decideix els colors i la forma de la web.

⚙️ script.js

Fa funcionar els botons i les accions.
