Com treballarem, sense paraules complicades

Si no has programat mai, comença aquí. Aquests passos serveixen per a totes les pràctiques.

Els tres fitxers de la primera pràctica

📄 index.html → allò que veus
🎨 style.css → colors i formes
⚙️ script.js → què fan els botons

Més endavant, la IA podrà posar aquestes tres peces dins d’un sol index.html. Per això no t’hauràs d’instal·lar res nou.

1

1. Baixa

A la sessió prem «Baixar ZIP». Normalment el trobaràs a la carpeta «Descàrregues» de Windows.

2

2. Extreu

A l’Explorador de Windows, clic dret al ZIP → «Extreu-ho tot» → «Extreu». Entra a la carpeta extreta.

3

3. Obre VS Code

Al menú superior: File → Open Folder (Fitxer → Obre carpeta). Tria la carpeta on hi ha index.html i prem «Selecciona carpeta».

4

4. Mira la web

Obre la mateixa carpeta a l’Explorador de Windows i fes doble clic a index.html. S’obrirà a Chrome.

5

5. Fes un canvi

A VS Code fes clic al fitxer que indiqui l’activitat. Prem Ctrl+F per trobar el fragment. Modifica només el que diu la fitxa.

6

6. Desa i actualitza

A VS Code prem Ctrl+S. Torna a Chrome i prem F5. Si no veus cap canvi, comprova que has obert el fitxer correcte.

7

7. Guarda el resultat

Quan ho demani la sessió, comprimeix la carpeta sencera en ZIP i entrega-la al professor. No publiquis res a Internet.

Si veus «index.html.txt»: no és el mateix que «index.html». Demana al professor que comprovi l’extensió del fitxer. Si la IA et dona React, npm o que instal·lis paquets: demana-li una versió HTML única que funcioni amb doble clic.
